# CCTV Weapon Detection System

## Project Description
An AI-based system that detects weapons from CCTV footage using Deep Learning and Computer Vision.

## Features
- Real-time weapon detection
- CCTV footage analysis
- AI-based detection
- User-friendly Streamlit interface

## Technologies Used
- Python
- Streamlit
- OpenCV
- YOLO
- Deep Learning
